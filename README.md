# 成就系统（LetsGal Studio 扩展）

适用于 LetsGal Studio / AVG Engine 的视觉小说成就系统扩展。成就由剧本卡片定义，支持剧情触发与全局变量条件触发；解锁时在游戏左上角弹出横幅并播放音效，并统一收录进一个类原生「鉴赏 / 存档」风格的成就页面。

当前版本：**v1.0.4**

---

## 功能一览

- **卡片定义成就**：在剧本里放「触发成就」「注册全局成就」卡片即可。扩展启动时扫描剧本自动收集，成就页面条目数与卡片数量一致；改 ID / 删卡片后旧条目自动消失。
- **剧情触发**：播放到「触发成就」卡片时解锁（一次性记录，重复播放不会重复记录）。
- **全局条件触发**：变量比较（≥、>、≤、<、==、!=）或高级表达式（`&&`、`||`、`!`、括号等），引擎监听变量变化自动解锁。
- **成就页面**：全屏列表，已解锁的排在未解锁上方；未解锁图标灰显；隐藏成就未解锁时图标显示为大问号、介绍逐字替换为问号，并永远排在列表最下方。
- **解锁横幅 + 音效**：左上角圆角横幅向下弹出，停留时长可配置；默认播放扩展内置音效，也可换成项目素材。
- **入口**：扩展自带「标题画面（含成就）」与「系统设置（含成就）」两个可视化界面

## 安装

### 方式一：直接导入（给使用者）

1. 下载或克隆本仓库。
2. 打开 Studio → **个性化 → 项目设置**，在扩展树顶部点「导入扩展」。
3. 选择本文件夹（或压缩包），启用扩展。

### 方式二：从源码构建（开发者）

`sdk/` 是 Studio 生成的 `@avg-studio/sdk` 本地副本，本仓库不包含它，`npm install` 前需要先准备：

1. 在 Studio 里新建一个本地扩展并点「初始化程序」，把它生成的 `sdk/` 文件夹复制到本目录。
2. 安装依赖并构建：

```bash
npm install
npm run build     # 生成 dist/index.js
```

3. 回到 Studio 导入 / 刷新扩展。

> 只想跑测试的话不需要 `sdk/`：`npm run test` 与 `npm run smoke` 用的是内置的 mock SDK。

开发命令：

| 命令 | 说明 |
| --- | --- |
| `npm run build` | 构建 `dist/index.js` |
| `npm run watch` | 监听源码持续构建 |
| `npm run typecheck` | TypeScript 类型检查（需要 `sdk/`） |
| `npm run test` | 表达式与定义单元测试 |
| `npm run smoke` | 集成冒烟测试（mock SDK + 假 DOM） |
| `npm run verify` | 类型检查 + 单测 + 构建 + 冒烟测试全套 |

## 分步教程

### 第 1 步：导入并启用扩展

个性化 → 项目设置 → 扩展树顶部「导入扩展」→ 选择本扩展文件夹 → 启用。启用后扩展树里能看到「成就系统 v1.0.4」及其「程序 / 界面」分组。

### 第 2 步：替换标题画面 / 系统设置（获得成就入口）

扩展自带两份可视化界面，按需绑定即可，不需要手动改任何 UI：

| 想加的入口 | 操作 |
| --- | --- |
| 标题画面「成就」按钮（位于「鉴赏」和「设置」之间） | 个性化 → 项目设置 → **游戏系统 → 标题画面** → 选择「成就系统 v1.0.4 → 标题画面（含成就）」 |
| 系统设置右下角「成就」按钮（位于「退出游戏」左侧） | 游戏系统 → **设置界面** → 选择「成就系统 v1.0.4 → 系统设置（含成就）」 |

绑定后，从标题画面或系统设置点「成就」即可打开成就页面；从系统设置进入时会自动关闭设置界面，关闭成就页后直接回到下层界面。

> 这两个界面是默认壳界面的副本，只加了成就按钮；如果你的项目已自定义过标题/设置界面，也可以按同样方式在 Studio 的可视化编辑器里自行加按钮，并把点击动作绑定到扩展方法「打开成就界面」。

### 第 3 步：卡片触发成就（剧情播放到就解锁）

1. 在剧本编辑器按 Tab → 「扩展 → 调用扩展方法」。
2. 选择「成就系统 v1.0.4 → 触发成就」，填写参数：

| 参数 | 说明 |
| --- | --- |
| 成就ID | 唯一标识，必填（例如 `first-meet`） |
| 成就名称 / 成就介绍 / 成就图标 | 成就页面与横幅显示的内容 |
| 隐藏成就 | 开启后未解锁时显示为问号 |
| 横幅停留(ms) | 0 = 使用扩展设置里的默认值 |
| 成就音效 | 选填；留空使用内置音效 |

3. 播放到该卡片时立即解锁并弹横幅。同 ID 只记录一次，重复播放不会重复记录。

### 第 4 步：全局变量条件成就（满足条件自动解锁）

1. 同样在「调用扩展方法」里选择「成就系统 v1.0.4 → 注册全局成就」。
2. 填写成就信息后设置条件，两种方式二选一：

- **简单条件**：选择「判断变量」+「比较方式」+「比较值」。例如变量 `好感度`、`>=`、`50`。
- **高级表达式**：直接写表达式，填写后优先于简单条件。例如：

```
好感度 >= 50 && route == "yuki"
```

3. 引擎启动时就会扫描该卡片并开始监听变量，满足条件即解锁——不需要真的播放到这张卡片，把它放在任意片段即可（放初始片段便于管理）。

### 第 5 步：打开成就页面

任选一种：

- 绑定第 2 步的界面后，从标题画面 / 系统设置点「成就」；
- 剧本卡片「打开成就界面」（可绑到自定义标题画面或菜单按钮上）；
- 扩展设置里开启「显示常驻入口按钮」，游戏画面角落会有一个「成就」悬浮按钮。

### 第 6 步：扩展设置说明

个性化 → 项目设置 → 扩展树 → 成就系统 → 程序设置：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 默认横幅停留(ms) | 3000 | 单条成就未单独指定时使用 |
| 成就音效音量(%) | 100 | 叠加在玩家音效音量上 |
| 默认成就音效 | 空 | 留空用扩展内置音效，也可选项目素材 |
| 隐藏成就解锁后揭示内容 | 开 | 关闭后隐藏成就解锁也保持问号 |
| 标题画面插入成就按钮 | 开 | 控制标题界面入口是否生效 |
| 系统设置成就按钮生效 | 开 | 控制系统设置入口是否生效 |
| 显示常驻入口按钮 | 关 | 游戏画面角落的悬浮「成就」按钮 |
| 常驻按钮位置 / 文字 | 右上 / 成就 | 悬浮按钮外观 |
| 主题强调色 | #ffd76a | 成就页面与横幅的强调色 |

### 第 7 步：测试与清理

- 调试时可用剧本卡片「重置成就数据」清空当前存档的解锁记录与运行时注册表。
- 想看全局条件是否命中，可用「刷新全局成就」卡片手动触发一次判断。
- 用「检查成就是否已解锁」卡片（带布尔返回值）可在 If 条件里根据成就状态分支。

## 条件表达式语法

| 写法 | 说明 |
| --- | --- |
| `affection >= 50` | 直接写变量名（支持中文） |
| `route == "yuki"` | 字符串比较 |
| `a > 1 && b != "x"` | 逻辑运算 `&&` `\|\|` `!`、括号 |
| `var("角色UUID.好感度") > 10` | 变量名含 `-`、`.` 等特殊字符时用 `var()` |
| `has("flag")` | 变量是否存在 |
| `len(name) > 2` | 字符串 / 数组长度 |

要点：

- 数值字符串（如 `"50"`）会按数字比较，兼容剧本变量以字符串存储的情况；
- 变量不存在（undefined）时所有比较都不满足，避免开局误触发，需要判断存在请用 `has()`；
- 表达式解析失败只会记录警告并按不满足处理，不会中断游戏。
